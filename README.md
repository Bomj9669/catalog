# Каталог питомцев «Лапки»

Учебный проект по дисциплине «Оптимизация веб-приложений».
Интернет-каталог на Node.js без сторонних библиотек.

## Как запустить

1. Установите Node.js версии 20 или новее.
2. Создайте каталог товаров командой `node generate-products.js`
3. Создайте файл стилей командой `node generate-theme.js`
4. Создайте папку `public/fonts` и скопируйте в неё шрифт `georgia.ttf`
   из папки `C:\Windows\Fonts`. Без шрифта сайт тоже работает,
   только другим шрифтом.
5. Запустите сервер командой `node server.js`
6. Откройте в браузере http://localhost:3000

Нагрузочный тест (при запущенном сервере, во втором терминале): `node bench.js`

## Что оптимизировано

| Работа | Что сделано |
|---|---|
| 4 | Фото уменьшены, размеры заданы заранее, отложенная загрузка |
| 5 | Лишние стили убраны, главные стили внутри страницы |
| 6 | Шрифт не прячет текст при загрузке, предзагрузка шрифта |
| 7 | Сборка с минификацией в папку dist (`node build.js`) |
| 8 | Карточки собираются строкой и вставляются один раз, высоты закрепляются в два цикла |
| 9 | Поиск с ожиданием паузы, прокрутка не чаще раза в 200 мс, один обработчик на все кнопки |
| 10 | Сжатие ответов gzip (`compress-test.js` показывает выигрыш) |
| 11 | Выдача по страницам, подгрузка при прокрутке, поиск на сервере |
| 12 | Кеширование: ETag, ответ 304, срок хранения картинок и шрифтов |
| 13 | Каталог хранится в памяти сервера |
